===============================================
 INSTALLATION (KEINE ADMIN-RECHTE NÖTIG!)
===============================================

1. ZIP-Datei entpacken in:
   - Eigene Dateien\spotify-quiz\
   - oder Desktop
   - oder USB-Stick (nur wenn das Laufwerk Schreibrechte erlaubt)

   Nicht nach C:\Programme oder in ein schreibgeschütztes Netzlaufwerk entpacken.

2. Spotify Developer App einrichten:
   a) Gehe zu: https://developer.spotify.com/dashboard
   b) Erstelle neue App
   c) Redirect URI: http://127.0.0.1:8000/api/v1/auth/callback
   d) Kopiere "Client ID"

3. Client ID eintragen:
   - Öffne .env mit Notepad
   - Ersetze "your-client-id-here" mit deiner Client ID
   - Speichern

4. Starten:
   - Doppelklick auf: launcher.bat
   - Browser öffnet sich automatisch
   - Die App bindet nur an 127.0.0.1 und benötigt normalerweise keine eingehende Firewall-Freigabe.

===============================================
 WICHTIG FÜR ÖD-LAPTOPS
===============================================

✓ KEINE Installation nötig
✓ KEINE Admin-Rechte erforderlich
✓ Läuft aus Benutzerverzeichnis
✓ Datenbank in eigenem Ordner (data/)
✓ Kein Internet für Quiz nötig (nur für Login)

⚠ Falls die Organisationsrichtlinie lokale Browser-Server blockiert:
   → IT-Freigabe für eine lokale Anwendung auf 127.0.0.1:8000 erforderlich.

⚠ Windows Defender SmartScreen:
   → "Weitere Informationen" → "Trotzdem ausführen"
   → Datei ist sicher, nur nicht signiert

===============================================
 VERWENDUNG
===============================================

1. Doppelklick auf launcher.bat
2. Browser öffnet sich automatisch
3. Für die lokale Demo ist kein Login erforderlich.
4. Quiz konfigurieren:
   - Zeitlimit: 5/10 Min oder unbegrenzt
   - Teams: 2 Standard-Teams
5. "START QUIZ" klicken
6. Musik raten!

BEENDEN:
→ Im Launcher-Fenster: Beliebige Taste drücken
→ Oder einfach Fenster schließen

===============================================
 PROBLEMBEHEBUNG
===============================================

Backend startet nicht:
→ Prüfe ob Port 8000 bereits belegt ist
→ Schließe andere Programme
→ Neustarten

Browser öffnet sich nicht:
→ Manuell öffnen: http://127.0.0.1:8000/frontend/

"Invalid Redirect URI" beim Login:
→ Prüfe Spotify Dashboard → Settings → Redirect URIs
→ Muss exakt sein: http://127.0.0.1:8000/api/v1/auth/callback

Token abgelaufen:
→ Wird automatisch erneuert, sofern Live-OAuth eingerichtet ist
→ Bei Problemen: data/quiz.db löschen → neu einloggen

Kein Ton:
→ Prüfe Windows-Lautstärke
→ Prüfe Browser-Lautstärke-Tab

===============================================
 TECHNISCHE DETAILS
===============================================

Enthaltene Komponenten:
- Backend: Python FastAPI (kompiliert)
- Frontend: React 90s-Retro-Design
- Datenbank: SQLite (data/quiz.db)
- Server: Uvicorn (embedded)

Systemanforderungen:
- Windows 10/11 (64-bit)
- 4 GB RAM (empfohlen)
- 100 MB freier Speicher
- Internetzugang für Spotify-Login

Ports:
- Backend: 127.0.0.1:8000 (localhost only)
- Nur lokale Verbindung auf 127.0.0.1; Spotify-Verbindungen nur bei aktivierter Live-Konfiguration

Daten:
- Quizdaten und lokale Tokens liegen im data/ Ordner
- Die App sendet nur für konfigurierte Spotify-Funktionen Daten an Spotify
- Die SQLite-Datei wird von der App nicht verschlüsselt; schützt den Benutzerordner entsprechend.
