===============================================
 INSTALLATION (KEINE ADMIN-RECHTE NÖTIG!)
===============================================

1. ZIP-Datei entpacken in:
   - Eigene Dateien\spotify-quiz\
   - oder Desktop
   - oder USB-Stick (nur wenn das Laufwerk Schreibrechte erlaubt)

   Nicht nach C:\Programme oder in ein schreibgeschütztes Netzlaufwerk entpacken.

2. Spotify Developer App einrichten:
   a) Gehe zu: https://developer.spotify.com/dashboard
   b) Erstelle neue App
   c) Redirect URI: http://127.0.0.1:8000/api/v1/auth/callback
   d) Kopiere "Client ID"

3. Client ID eintragen:
   - Öffne .env mit Notepad
   - Ersetze "your-client-id-here" mit deiner Client ID
   - Speichern

4. Starten:
   - Doppelklick auf: launcher.bat
   - Die Batch-Datei startet intern launcher.ps1 mit PowerShell und bleibt bei Fehlern offen.
   - Für einen Neustart: Doppelklick auf restart-backend.bat
   - Browser öffnet sich automatisch
   - Die App bindet nur an 127.0.0.1 und benötigt normalerweise keine eingehende Firewall-Freigabe.

===============================================
 WICHTIG FÜR ÖD-LAPTOPS
===============================================

✓ KEINE Installation nötig
✓ KEINE Admin-Rechte erforderlich
✓ KEIN Python, Node.js oder Git auf dem Ziel-PC erforderlich
✓ Läuft aus Benutzerverzeichnis
✓ Datenbank in eigenem Ordner (data/)
✓ Kein Installer und keine zusätzliche Launcher-EXE

Die Portable-Ausgabe enthält genau eine projekt-eigene EXE:
- spotify-quiz-backend.exe

Start und Neustart erfolgen ausschließlich über BAT/PowerShell:
- launcher.bat
- launcher.ps1
- restart-backend.bat

⚠ Falls die Organisationsrichtlinie lokale Browser-Server blockiert:
   → IT-Freigabe für eine lokale Anwendung auf 127.0.0.1:8000 erforderlich.

⚠ Windows Defender SmartScreen:
   → "Weitere Informationen" → "Trotzdem ausführen"
   → Die Backend-EXE ist nicht codesigniert; die lokale Richtlinie entscheidet über die Ausführung.

===============================================
 PROBLEMBEHEBUNG
===============================================

Backend startet nicht:
→ Fehlermeldung im Launcher-Fenster lesen
→ Prüfen, ob Port 8000 bereits belegt ist
→ Prüfen, ob spotify-quiz-backend.exe vorhanden und durch die lokale Sicherheitsrichtlinie ausführbar ist
→ Neustarten

Browser öffnet sich nicht:
→ Manuell öffnen: http://127.0.0.1:8000/frontend/

"Invalid Redirect URI" beim Login:
→ Prüfe Spotify Dashboard → Settings → Redirect URIs
→ Muss exakt sein: http://127.0.0.1:8000/api/v1/auth/callback

Token abgelaufen:
→ Wird automatisch erneuert, sofern Live-OAuth eingerichtet ist
→ Bei Problemen neu authentifizieren

Kein Ton:
→ Prüfe Windows-Lautstärke
→ Prüfe Browser-Lautstärke-Tab

===============================================
 TECHNISCHE DETAILS
===============================================

Enthaltene Komponenten:
- Backend: Python/FastAPI als einzelne PyInstaller-Binary spotify-quiz-backend.exe
- Launcher: BAT + PowerShell, keine zusätzliche Launcher-EXE
- Frontend: gebautes React/Vite-Bundle
- Datenbank: SQLite (data/quiz.db)
- Server: Uvicorn im Backend-Bundle

Systemanforderungen:
- Windows 10/11 (64-bit)
- PowerShell aus Windows
- 4 GB RAM (empfohlen)
- ausreichend freier Speicher für ZIP, entpackte Anwendung und lokale Daten
- Internetzugang für Spotify-Login und Spotify-Wiedergabe

Nicht erforderlich:
- Python-Installation
- Node.js-Installation
- Git-Installation
- Administratorrechte

Ports:
- Backend: 127.0.0.1:8000
- Nur lokale Verbindung auf 127.0.0.1; Spotify-Verbindungen nur bei aktivierter Live-Konfiguration

Daten:
- Quizdaten und lokale Authentifizierungsdaten liegen im data/ Ordner
- Die App sendet nur für konfigurierte Spotify-Funktionen Daten an Spotify
- Die SQLite-Datei wird von der App nicht verschlüsselt; der Benutzerordner muss entsprechend geschützt werden.
